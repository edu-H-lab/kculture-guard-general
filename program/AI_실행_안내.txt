================================================================================
  우리 문화 수호대 — AI 실행 안내
================================================================================
이 문서는 「생각친구」·「교사용 AI 분석」을 쓰기 위한 설정 방법입니다.
AI 없이 체험만 할 때는 program\1_실행하기.bat 만 실행하면 됩니다.


--------------------------------------------------------------------------------
1. 무엇이 다른가요?
--------------------------------------------------------------------------------

  1_실행하기.bat
    · AI 없이 실행합니다.
    · 활동 체험, 마이크(애국가 등)는 사용할 수 있습니다.
    · 생각친구·교사용 AI 분석은 정해진 질문/응답 위주로만 동작하거나
      AI 분석 버튼을 쓸 수 없을 수 있습니다.

  2_AI포함_실행하기.bat
    · source\server 의 Node 서버를 켭니다. (주소 예: http://localhost:8780)
    · 생각친구 대화·정리문, 교사용 「AI로 분석하기」를 사용할 수 있습니다.
    · Node.js 설치와 .env(API 키) 설정이 필요합니다.


--------------------------------------------------------------------------------
2. 준비물
--------------------------------------------------------------------------------

  1) Node.js (LTS 권장)
     https://nodejs.org 에서 설치합니다.
     설치 확인: 명령 프롬프트에  node -v  를 입력해 버전이 나오면 됩니다.

  2) Gemini API 키
     Google AI Studio 등에서 발급받은 키를 사용합니다.
     (키는 절대 화면·제출 USB·공개 저장소에 올리지 마세요.)


--------------------------------------------------------------------------------
3. 최초 1회 설정
--------------------------------------------------------------------------------

  1) source\server\.env.example 파일을 복사합니다.
  2) 복사한 파일 이름을 .env 로 바꿉니다.
     위치: source\server\.env
  3) .env 파일을 메모장으로 열어 아래를 채웁니다.

       GEMINI_API_KEY=여기에_발급받은_키
       THINKING_FRIEND_PROVIDER=gemini

     (예시 파일에 다른 항목이 있어도, 위 두 줄이 가장 중요합니다.)

  4) program\2_AI포함_실행하기.bat 을 두 번 클릭합니다.
  5) 잠시 뒤 브라우저가 열리면 「프로그램 실행하기」로 들어갑니다.
  6) 실행 중에는 bat로 연 검은 창을 닫지 마세요.


--------------------------------------------------------------------------------
4. .env 가 없을 때
--------------------------------------------------------------------------------

  2_AI포함_실행하기.bat 을 실행해도 .env 가 없으면
  · 서버는 켜질 수 있지만
  · 생각친구는 정해진 질문으로만 동작하고
  · 교사용 AI 분석 버튼은 쓸 수 없을 수 있습니다.

  안내 메시지가 나오면 위 「3. 최초 1회 설정」을 진행한 뒤
  다시 bat를 실행하세요.


--------------------------------------------------------------------------------
5. Node.js 가 없을 때
--------------------------------------------------------------------------------

  2_AI포함_실행하기.bat 은 Node.js가 없으면
  자동으로 1_실행하기.bat(AI 없이)으로 넘어갑니다.
  AI 기능을 쓰려면 Node.js(LTS)를 설치한 뒤 다시 실행하세요.


--------------------------------------------------------------------------------
6. 확인 방법
--------------------------------------------------------------------------------

  브라우저에서 아래 주소를 열어 보세요. (서버가 켜진 상태)

    http://localhost:8780/api/thinking-friend/health

  정상이면 대략 이런 내용이 보입니다.

    {"ok":true,"provider":"gemini"}

  ok 가 false 이거나 페이지가 안 열리면
  · bat 창이 아직 열려 있는지
  · .env 의 GEMINI_API_KEY / THINKING_FRIEND_PROVIDER 가 맞는지
  · 방화벽·다른 프로그램이 8780 포트를 쓰는지
  를 확인해 주세요.


--------------------------------------------------------------------------------
7. 주의
--------------------------------------------------------------------------------

  · .env 와 API 키는 제출물·USB·깃허브 등에 넣지 마세요.
  · AI 결과는 참고용입니다. 수업 판단은 선생님이 하세요.
  · 교사용 AI 분석은 학생 이름을 서버로 보내지 않습니다.
